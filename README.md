# Control de Pagos — Fabricación Propia Santiago

Dashboard en vivo conectado a Google Sheets para el seguimiento de pagos a talleres de confección.

## Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Dashboard principal (abre este en el navegador) |
| `historico_pagos.csv` | Resumen histórico por mes |
| `top_talleres.csv` | Ranking de talleres |
| `flujo_provision.csv` | Órdenes en confección |
| `detalle_pagos.csv` | Detalle completo de pagos |

## Cómo usar

1. Activar GitHub Pages en **Settings → Pages → Branch: main → / (root)**
2. Acceder al dashboard en: `https://TU_USUARIO.github.io/donnely-pagos`
3. Los datos se cargan en vivo desde Google Sheets cada vez que abres el dashboard

## Fuente de datos

Los datos provienen de la planilla P2 Fabricación Propia publicada en Google Sheets como CSV.  
Para actualizar: editar en Google Sheets → los cambios se reflejan automáticamente al recargar el dashboard.
